# **App Name**: Ethiopia LocalLens

## Core Features:

- Multilingual AI Product Search: Enable users to search for products using voice or text input in Amharic, Tigrinya, Oromo, and English. The tool must use AI to map colloquial terms to product names.
- Location-Based Search Filtering: Filter search results by the user's current location, displaying the nearest options first.
- Real-Time Price Comparison: Display prices from local shops, ranked from low to high, with 'In Stock' or 'Out of Stock' indicators.
- Shop Details and Navigation: Display shop profiles with operating hours, contact info, payment options, and navigation integration.
- Simplified Shop Onboarding: Provide a simple, mobile-first interface for shop owners to upload inventory and prices.
- Inventory Management: Allow shop owners to update the price or stock status of their products using a simple interface.

## Style Guidelines:

- Primary color: Vibrant yellow (#FFC107) to represent the energy and dynamism of Ethiopian commerce.
- Background color: Light beige (#F5F5DC) providing a neutral and clean backdrop for the vibrant primary color.
- Accent color: Warm orange (#FF7043) to draw attention to important UI elements like calls to action.
- Headline font: 'Poppins' sans-serif for headlines, a contemporary, geometric font that offers a balance of professionalism and approachability.
- Body font: 'PT Sans' humanist sans-serif font for body text, it combines modernity with a touch of warmth.
- Simple, clear icons for product categories and shop details, ensuring easy recognition across languages.
- Mobile-first layout with clear, consistent spacing and padding to ensure readability and ease of use.
